# 记账日报 · THE DAILY LEDGER

**简体中文** | [English](README_EN.md)

> 纯本地 Android 自动记账 —— 付款后自动弹出记账窗，数据永不出手机。
> 复古报纸风 UI · 零第三方运行时依赖 · 零 INTERNET 权限

---

## ✨ 这是什么

一款「付款后自动弹出记账窗」的 Android 记账应用。微信/支付宝付款、转账、发红包，或美团/抖音等平台直连银行卡扣款时，自动弹出快速记账小窗（自动预填金额与付款时间），让你 2 秒记完一笔。

**隐私设计**：manifest 不申请 INTERNET 权限——你的每一笔账单在物理上就无法离开手机。

## 📰 主要特性

- **自动弹窗记账**：通知监听 + 银行扣款短信 + 无障碍（微信转账/红包识别）三通道，付款后自动弹出记账窗并预填金额
- **连续付款队列**：一次付多笔（金额各不相同）逐笔保留，打开后逐笔确认，不错不漏
- **复古报纸风**：报头、铅字分类块、印章红、斜纹柱状图——记账也能有翻报纸的仪式感
- **三版面**：壹·记账（流水+分类图）/ 贰·统计（年度月度支出）/ 叁·我的（权限管理+数据导出）
- **自定义分类、滑块删除、年月直选、记账时间可修改**
- **CSV 导出**：全部记录与触发日志一键导出到下载目录

## 🔐 权限说明（全部可选、全部本地）

| 权限 | 用途 |
|---|---|
| 通知监听 | 核心能力：识别微信/支付宝/美团/抖音等支付通知 |
| 悬浮窗 / 后台弹出界面 | 让记账窗能在其他应用上层弹出（小米需单独开启） |
| 银行短信（可选） | 兜底识别银行卡扣款短信（平台直连支付场景） |
| 无障碍（可选） | 识别微信好友转账/红包（微信不发系统通知，仅监听微信窗口） |

> 本应用**不申请 INTERNET 权限**，无账号、无云同步、无广告、无埋点。

## 🛠 构建

```
Android Studio Ladybug+ / Gradle 8.13 · minSdk 24 · targetSdk 36 · Java
git clone https://github.com/KlingNaA/daily-ledger.git
```
直接用 Android Studio 打开，`assembleDebug` 即可。无任何密钥/签名配置。
